Quickstart

Three steps from key to first successful call. Base URL: https://yourdomain.com

1 · Get a key

Pick a plan below. Keys look like dpk_live_… and are shown once — store them safely.

2 · Send it

Pass the key as a Bearer token on every request. One header, no SDK required.

3 · Watch usage

GET /v1/usage returns quota, consumed credits and the last 14 days per day.

curl https://YOUR-WORKER.workers.dev/v1/validate \
  -H "Authorization: Bearer dpk_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"meter":true}'

# HTTP 200
# {"valid":true,"plan":"pro","quota":50000,"used":1,"remaining":49999}

API Reference

The key endpoints every integration uses. Add your own endpoints below them — see CUSTOMIZE.md.

POST/v1/validate

Validates a key, meters one credit (unless meter:false) and returns the live quota state. Call it at the top of your own API handlers to enforce access.

Headers

HeaderRequiredDescription
AuthorizationrequiredBearer dpk_live_… — the customer key
Content-Typeoptionalapplication/json

Body

FieldTypeDescription
meterbooleanDefault true. Set false to check a key without consuming a credit.

Responses

200 {"valid":true,"plan":"pro","quota":50000,"used":42,"remaining":49958}
401 {"error":"invalid_key"}          — missing or unknown key
403 {"error":"key_revoked","key_id":"k_…"}
429 {"error":"quota_exceeded","quota":1000,"used":1000}
GET/v1/usage

Returns the key's plan, quota, total usage and the last 14 days per day — the data behind your customers' usage dashboards.

Headers

HeaderRequiredDescription
AuthorizationrequiredBearer dpk_live_…

Responses

200 {"plan":"pro","quota":50000,"used":512,"remaining":49488,
     "days":[{"day":"2026-09-18","count":87},{"day":"2026-09-17","count":64}]}
