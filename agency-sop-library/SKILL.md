# Agency SOP Library

A repeatable operating system for small digital agencies. Every process follows the same anatomy: *when to use → the process → copy-paste assets → rules & red flags → what good looks like → an AI prompt to adapt it.*

## How to use this skill

1. Open `references/INDEX.md` — the lifecycle map of all 24 SOPs with triggers and what each one gives you.
2. Installing the system? Follow `references/PLAYBOOK-14D.md` — a 14-day plan that installs the library without breaking your current delivery.
3. Try the included sample SOPs in `references/samples/`:
   - `01-lead-qualification.md` — score every inquiry 0–100, decide pursue/park in minutes
   - `09-comms-rules.md` — the 7-clause comms contract that prevents 80% of client friction
   - `11-status-update-template.md` — the weekly update that survives busy weeks (verdict first, vanity banned)
