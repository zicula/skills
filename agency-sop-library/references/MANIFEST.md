## Quality rules baked into every SOP

1. **Same anatomy:** When to use → Process → Copy-paste assets → Rules & red flags → What good looks like → AI adapt prompt.
2. **Copy-paste real:** every email/script/table is complete text with `[FILL-IN]` slots — not outlines.
3. **Cross-referenced:** SOPs cite each other by number; the library works as one operating system.
4. **1–2 pages each:** written for a busy owner; no filler, no theory chapters.
5. **Adaptable by AI:** each SOP closes with a ready prompt to re-tune it to the buyer's niche, rates, and voice.

## Placeholder convention

`[BRACKETS]` = buyer fills in. Common ones: `[NAME]`, `[SERVICE]`, `[NICHE]`, `[FLOOR]` (floor rate), `[BOOKING LINK]`, `[SLA]`, `[RATE]`, `[X]`. Money figures are USD examples — swap any currency, the math holds.
