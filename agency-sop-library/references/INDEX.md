# Agency SOP Library — INDEX

Every SOP follows the same anatomy: *when to use → the process → copy-paste assets → rules & red flags → what good looks like → an AI prompt to adapt it to your agency.*

## If you only install 6 SOPs first (highest leverage for a 1–10 person agency)

1. **SOP-09** Communication Rules — ends channel chaos from day one of every client
2. **SOP-11** Weekly Status Update — kills "how's it going?" forever
3. **SOP-12** Revision Policy — the #1 profit leak, plugged
4. **SOP-01** Lead Qualification — stops bad clients before they cost you
5. **SOP-04** Pricing Calculator — never quote from vibes again
6. **SOP-16** Monthly Report — makes retainer value visible (retention weapon)

## How to install (choose your route)

- **Notion (recommended):** Settings & members → *Import* → **Text & Markdown** → select all 24 files in `sop/`. Each becomes a full page in seconds.
- **Notion as a database:** create a database → ⋯ → *Merge with CSV* → `notion-import.csv`. You get Title / Category / Body columns; set Category as a Select and filter by lifecycle stage.
- **Google Docs / ClickUp / Confluence:** paste each `.md` file; formatting survives in every major tool.
- **AI-first:** paste any SOP + its built-in adapt prompt into your assistant of choice; every SOP ends with one written for exactly that.

## Conventions

- `[BRACKETS]` = fill in with your details. Every SOP is written to work after one 10-minute adaptation pass.
- Dollar figures are placeholders — the logic holds at any currency or rate; swap in your own numbers (SOP-04 computes yours).
- SOPs cross-reference each other by number (e.g., "see SOP-14") — the library is designed as one operating system, not 24 loose documents.

## Full lifecycle in one paragraph

Score the lead (01) → run the call (02) → propose with three options (03) at defended prices (04) → follow a fixed cadence (05) → welcome same-day (06) → kick off with a live doc (07) → collect access with dates and owners (08) → install the comms contract (09) → baseline the plan (10) → update weekly without fail (11) → triage feedback into rounds (12) → QA before every send (13) → price every "quick add" (14) → escalate on a ladder, never in anger (15) → report monthly with a verdict (16) → review quarterly (17) → upsell on triggers (18) → score retainer health monthly (19) → pulse feedback at milestones (20) → hand over ownership cleanly (21) → bank the testimonial within 24 hours (22) → ask for the referral at the high point (23) → win back the quiet ones patiently (24).
