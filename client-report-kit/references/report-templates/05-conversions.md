**Filling rules**

- Name key events exactly as they're registered in GA4 (`generate_lead`, not "the contact form one") so the client can find them.
- Every action must cite the data point that motivated it — "publish more content" is not an action.
- Expected effects are ranges and hypotheses, never promises. Write "we expect… if…" not "will deliver…".
- If conversions fell, the reason and the counter-move go in the story section — never leave a red number unexplained on this page.
