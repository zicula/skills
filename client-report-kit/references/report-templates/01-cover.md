## Fill-in checklist (delete this section in the final PDF)

- [ ] Client legal/brand name spelled exactly as they write it
- [ ] Period matches the data pull window (1st–last day of the month, client's time zone)
- [ ] GA4 property ID used: `[\_\_\_\_\_\_\_\_]` (note it in your internal tracker, not in the client copy)
- [ ] GSC property used: `[https://domain or domain-property]`
- [ ] Covers GA4 + Search Console only — if you also delivered paid/social data this month, say so in the exec summary so scope is explicit
- [ ] Cover is page 1 of 5; the four sections that follow are: Executive Summary → Traffic → Search Performance → Conversions

## Consistency rules for the whole report

1. **One number, one source.** Every figure traces to GA4 or Search Console for the stated period. If you recompute mid-month, update everywhere.
2. **Same period label everywhere.** Pick "March 2026" or "01–31 Mar 2026" and use it on every page.
3. **Deltas shown as signed values.** Use `+12.4%` / `-3.1%`, never "up a bit".
4. **Rounding.** Percentages to 1 decimal, counts to whole numbers, currency to whole units unless under 100.
5. **Tone.** Calm, specific, no hype. The client should finish page 2 knowing exactly what happened and what happens next.
