# ชุดพรอมป์ AI เขียนเชิงพรรณนา — ภาษาไทย (12 พรอมป์)

> วาง "บล็อกกฎ" (จาก `00-how-to-use.md`) ก่อนทุกครั้ง แล้วแทนที่ `[วาง: …]` ด้วยข้อมูลจริง
> ผลลัพธ์เป็นร่างแรก — ต้องตรวจแก้ก่อนส่งถึงลูกค้าทุกครั้ง

```
คุณกำลังเขียนรายงานรายเดือนให้ลูกค้า กฎเด็ดขาด:
1. ใช้เฉพาะตัวเลขที่ฉันให้เท่านั้น ห้ามเดา ห้ามประมาณ ห้ามคาดเดาเพิ่มเอง
   ถ้าข้อมูลไม่พอ ให้เขียน [ข้อมูลไม่ครบ: ต้องการอะไร] แทนการเดา
2. ภาษาที่เจ้าของธุรกิจเข้าใจ ไม่ใช้ศัพท์เทคนิคโดยไม่อธิบายสั้น ๆ
3. โทนมืออาชีพ สุขุม เจาะจง ไม่ฟ้องเกินจริง
4. เขียนแบบ active voice ระบุหน้า/คีย์เวิร์ด/ช่องทาง/แคมเปญที่เจาะจงเสมอ
5. แยก "สิ่งที่ข้อมูลชี้" ออกจาก "ข้อสันนิษฐาน" — ข้อสันนิษฐานต้องขึ้นต้นด้วย
   "น่าจะเกิดจาก" หรือ "เราประเมินว่า"
6. เปลี่ยนแปลงแสดงเครื่องหมาย (+12.4% / -3.1%) ทศนิยม 1 ตำแหน่ง
   อันดับเฉลี่ย: ต่ำกว่าคือดีกว่า — ต้องบอกกลาย ๆ ทุกครั้ง
7. คุมความยาวตามที่ระบุเป๊ะ
```

**1 — บทสรุปผู้บริหาร** `[วาง: ตาราง KPI เดือนนี้ vs เดือนก่อน + งานที่ส่งมอบ]`

```
เขียนบทสรุปผู้บริหารของรายงานรายเดือน ลูกค้า: [ชื่อ] ธุรกิจ: [ประเภท] เดือน: [เดือน ปปปป]
[วาง: ตาราง KPI] งานที่ส่งมอบเดือนนี้: [วาง: 1–3 รายการ]
เขียน 3–4 ประโยค: (1) ตัวเลขที่นิยามเดือนนี้ พร้อมเปอร์เซ็นต์เปลี่ยนแปลงเป๊ะ;
(2) ปัจจัยหลักที่ขับเคลื่อน ผูกกับหน้า/คีย์เวิร์ด/แคมเปญที่เจาะจง; (3) ด้านตรงข้ามอย่างตรงไปตรงมา
(อะไรทำได้แย่ลงหรือเท่าเดิม); (4) เดือนหน้าสิ่งนี้ปูทางอะไรไว้ โดยไม่สัญญาเกินตัว
ปิดท้ายด้วย 3 หัวข้อย่อย: สามตัวเลขที่ลูกค้าควรจำ
```

**2 — อธิบายการเปลี่ยนแปลงรายเดือน** `[วาง: เซสชันแยกช่องทาง + landing page 5 อันดับแรก]`

```
อธิบายการเปลี่ยนแปลงของทราฟฟิกเทียบเดือนก่อน [วาง: ข้อมูล]
เขียน 4–6 ประโยค: ช่องทางใดอธิบายการเปลี่ยนแปลงส่วนใหญ่ (คำนวณสัดส่วนจากข้อมูลที่ให้),
หน้าใดรับผิดชอบ (เอ่ยชื่อหน้า), แยกให้ชัดระหว่างปัจจัยตามฤดูกาลกับปัจจัยใหม่ และถ้าช่องทางไหนลด
ให้บอกว่าเซสชันไปโผล่ที่ไหนแทน ห้ามเดาสาเหตุ: ถ้าข้อมูลไม่ชี้เหตุผล ให้เขียนว่า "กำลังตรวจสอบอยู่"
```

**3 — อธิบายเมื่อทราฟฟิกตก** `[วาง: เซสชันรายสัปดาห์/รายวันของสองเดือน, ช่องทาง, สิ่งที่แก้ไขในเว็บ]`

```
ทราฟฟิกของลูกค้าลดลง เขียนหัวข้ออธิบายสำหรับรายงาน ลูกค้า: [ชื่อ] การลดลง: [เช่น -18.4%]
[วาง: ข้อมูล]
เขียน 4–6 ประโยค: (1) พูดถึงการลดลงตรง ๆ พร้อมตัวเลขเป๊ะ — ไม่ต้องเก็บ; (2) ระบุว่าเกิด "เมื่อไหร่"
และฉับพลันหรือค่อยเป็นค่อยไป; (3) ใช้ข้อมูลที่ให้แยกสามความเป็นไปได้ — การเปลี่ยนวิธีวัด,
การแก้เว็บ, ดีมานด์/ฤดูกาล — แล้วชี้ว่าหลักฐานสนับสนุนแบบไหน; (4) ปิดด้วยขั้นตอนวินิจฉัยที่
กำลังทำอยู่แล้ว โทน: สุขุม คุมสถานการณ์ได้
```

**4 — อธิบายเมื่อทราฟฟิกพุ่ง** `[วาง: เซสชันรายสัปดาห์/รายวัน, หน้า top, ช่องทาง]`

```
เดือนนี้ทราฟฟิกพุ่ง เขียนคำอธิบายโดยยังไม่รับเครดิตล้วน ๆ [วาง: ข้อมูล]
เขียน 4–6 ประโยค: วัดการพุ่งเป็นตัวเลขเป๊ะ (เปอร์เซ็นต์ + ช่วงเวลา), ระบุที่มาแม่นยำ
(หน้าไหน ช่องทางไหน คีย์เวิร์ดใดถ้ามองเห็น), แยกสาเหตุครั้งเดียว (โดนแชร์, สื่อพาทำ, ฤดูกาล)
ออกจากสาเหตุทำซ้ำได้ (ติดอันดับใหม่, แคมเปญ) และปิดด้วยวิธีที่จะทดสอบว่าระดับนี้อยู่ได้หรือไม่
ห้ามอ้างสาเหตุที่ข้อมูลไม่พิสูจน์
```

**5 — เล่าผล Search Console** `[วาง: คลิก, อิมเพรสชัน, CTR, อันดับเฉลี่ย (สองเดือน), คีย์เวิร์ด 5 อันดับ, หน้า 5 อันดับ]`

```
เขียนหัวข้อตีความผลหน้า Search Console ห้ามเล่าซ้ำตาราง — ให้ตีความ [วาง: ข้อมูล]
ตอบใน 4–6 ประโยค: (1) คลิกที่เพิ่มขึ้น เพราะอิมเพรสชันโต (ครอบคลุมดีมานด์เพิ่ม) หรือเพราะ CTR ดีขึ้น
(ไตเติลเราชนะ)? อธิบายการคำนวณเป็นภาษาคนธรรมดา; (2) คีย์เวิร์ดหรือหน้าใดอธิบายการเปลี่ยนแปลง
ส่วนใหญ่; (3) อันดับเฉลี่ยขยับอย่างไร และแปลว่าอะไรในทางปฏิบัติ (ย้ำ: ต่ำลงคือดีขึ้น);
(4) มองไปข้างหน้าหนึ่งประโยค ผูกกับคีย์เวิร์ดหน้า 2 ถ้าให้มา
```

**6 — วิเคราะห์คีย์เวิร์ดที่มีโอกาส** `[วาง: คีย์เวิร์ดอันดับ 11–20 จำนวน 5–10 คำ พร้อมอิมเพรสชันและหน้าที่ติด]`

```
เขียนบรีฟ "quick wins" จากคีย์เวิร์ดหน้า 2 [วาง: ข้อมูล]
ทีละคีย์เวิร์ด (สูงสุด 5) ประโยคละ 2: ทำไมถึงมีโอกาสชนะ (อันดับปัจจุบัน + อิมเพรสชัน = ทราฟฟิกที่
รออยู่) และการปรับปรุงที่จะทำเป็นรูปธรรม (เพิ่มช่วง FAQ ตอบคำถามนี้, ปรับไตเติลเพื่อ CTR,
เพิ่มลิงก์ภายในจาก [หน้าที่เกี่ยว], ขยายเนื้อหาตรง search intent) ปิดท้าย: เหล่านี้คือข้อสันนิษฐาน
อันดับมักขยับเป็นสัปดาห์ ไม่ใช่วัน เรียงตามอิมเพรสชันจากมากไปน้อย
```

**7 — เล่าเรื่องการคอนเวอร์ชัน** `[วาง: ตาราง key event, คอนเวอร์ชันแยกช่องทาง, conversion rate สองเดือน]`

```
เขียนหัวข้อเล่าเรื่องการคอนเวอร์ชัน ลูกค้า: [ชื่อ] ธุรกิจ: [ประเภท] [วาง: ข้อมูล]
เขียน 5–7 ประโยค: (1) พาดหัว: คอนเวอร์ชันรวมพร้อมเปอร์เซ็นต์เปลี่ยนแปลงเป๊ะ และ conversion rate
ขยับตามไหม (ทราฟฟิกมากขึ้น หรือทราฟฟิกดีขึ้น — ต้องแยกให้ชัด); (2) ประเภทคอนเวอร์ชันใดขับเคลื่อน
บนหน้าไหน; (3) ช่องทางแข็งสุดและอ่อนสุดตาม conversion rate เอ่ยตรง ๆ; (4) ประโยคเชื่อมไปสู่แผน
เดือนหน้า ถ้าคอนเวอร์ชันลด: พูดในประโยคแรก, ให้สาเหตุที่น่าจะเป็นจากข้อมูล และมาตรการแก้ที่วางไว้
แล้ว ไม่ต้องแต่งสี
```

**8 — ข้อเสนอแผนเดือนหน้า** `[วาง: KPI, คีย์เวิร์ดหน้า 2, บันทึกคอนเวอร์ชัน, ทรัพยากรที่มี]`

```
เสนอแผนการทำงานเดือนหน้า (3–5 ข้อ ห้ามเกิน) สำหรับ [ลูกค้า] ข้อจำกัด: [เช่น ~20 ชั่วโมง ไม่มี
ทีม dev] [วาง: ข้อมูล]
แต่ละข้อเขียนเป๊ะ: การกระทำ (ของที่ส่งมอบได้จริง ไม่ใช่ "ปรับ SEO ให้ดีขึ้น"), เพราะอะไร
(ชี้ข้อมูลตัวไหนที่มันแก้), คาดหวัง (ช่วงผลแบบซื่อสัตย์ + เงื่อนไขที่ต้องจริง เช่น "ลีด +5–10%
ถ้า CTR เดิมอยู่"), ก้าวแรก (วันแรกทำอะไร) เรียงตามผลกระทบที่คาด ตัดทุกข้อที่ไม่อ้างข้อมูล
จากที่วางให้
```

**9 — รีไรต์เป็นภาษาคนธรรมดา** `[วาง: ย่อหน้าที่เทคนิคเกินไป]`

```
เขียนใหม่เป็นภาษาที่เจ้าของธุรกิจไม่มีพื้นเบื้องหลังการตลาดอ่านรู้เรื่อง เก็บตัวเลขทุกตัวเป๊ะ ๆ
เหตุการณ์และลำดับเดิม เปลี่ยนศัพท์เทคนิคเป็นคำธรรมดา (อธิบายสั้น ๆ ได้ครั้งเดียวต่อศัพท์)
ประโยคเฉลี่ยไม่เกิน 22 คำ ห้ามเพิ่มข้อเรียกร้องใหม่ [วาง: ย่อหน้า]
```

**10 — ชัยชนะ & สิ่งที่ต้องจับตา** `[วาง: KPI + การขยับที่น่าสนใจ 3–5 รายการของหน้า/คีย์เวิร์ด]`

```
เขียน (ก) ชัยชนะ 3 ข้อ และ (ข) สิ่งที่ต้องจับตา 3 ข้อ สำหรับบทสรุปผู้บริหาร [วาง: ข้อมูล]
ชัยชนะ: ผลที่วัดได้ + เหตุผลสั้น 1 ประโยค — เฉพาะที่ข้อมูลชี้จริง จับตา: ความเสี่ยงพร้อมตัวเลข +
สิ่งที่กำลังแก้อยู่แล้ว (ห้ามปวดหัวโดยไม่มีแผน) ข้อละไม่เกิน 20 คำ
```

**11 — เตรียมประชุมลูกค้า** `[วาง: รายงานที่กรอกแล้วหรือตารางสรุป + คำถามค้างจากเดือนก่อน]`

```
เตรียมฉันสำหรับคอลรายเดือนกับ [ลูกค้า] [วาง: ข้อมูล]
ส่งกลับ: (1) 3 คำถามที่เขาน่าจะถาม เรียงตามความน่าจะเป็น เขียนแบบคนไม่ใช่สายการตลาดถาม;
(2) คำตอบ 2 ประโยคต่อคำถาม ยึดเฉพาะข้อมูลที่วางให้; (3) จุดอ่อนของเดือนนี้ที่เขาอาจแทง พร้อมวิธี
วางกรอบอย่างตรงไปตรงมา (ยอมรับ + ชี้แผนแก้); (4) คำถาม 1 ข้อที่ฉันควรถาม "เขา" เพื่อรู้บริบท
ธุรกิจที่ตัวเลขไม่บอก
```

**12 — อีเมลส่งรายงาน** `[วาง: ชัยชนะ 3 ข้อ + ชื่อไฟล์รายงาน + โฟกัสเดือนหน้า]`

```
เขียนอีเมลส่งรายงานรายเดือน ผู้รับ: [ชื่อ] ตำแหน่ง: [บทบาท] จาก: [ชื่อคุณ]
1) หัวข้ออีเมล: ตัวเลขสำคัญที่สุดของเดือน (ห้ามใช้ "รายงานประจำเดือนของคุณ") 2) ทักทาย + หนึ่งบรรทัด
กับผลหลัก 3) สองหัวข้อย่อย: ชัยชนะที่เขาสนใจสุด 4) หนึ่งบรรทัด: รายงานแนบมา — อ่าน 3 นาที
5) หนึ่งบรรทัด: เดือนหน้าเราโฟกัสอะไร 6) ลงท้ายเสนอคุย 15 นาที รวมไม่เกิน 120 คำ ไม่มีอิโมจิ
ไม่มีเครื่องหมายตกใจ
```
